# Amit Gupta Finance - Professional Portfolio Website

A premium financial coaching and insurance expert portfolio website built with modern web technologies.

## 🎯 Project Overview

This is the official website for Amit Gupta, a financial coach and insurance expert. The site showcases services, testimonials, and provides easy contact options for potential clients.

## 📋 Features

- ✅ Professional dark theme with gold accents
- ✅ Responsive design (mobile, tablet, desktop)
- ✅ Smooth animations and transitions
- ✅ WhatsApp integration
- ✅ Services showcase
- ✅ Client testimonials section
- ✅ Contact forms
- ✅ Fast loading with optimized assets

## 🛠 Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Design**: Custom CSS with responsive grid system
- **Fonts**: Cormorant Garamond, DM Sans, Bebas Neue

## 📂 Project Structure

